# 国科大在线学习助手

适用于 Microsoft Edge 的非官方浏览器扩展。在国科大在线的学生学习页开启一次「连续切换」，即可在同一标签页按课件顺序接续视频和 PDF，并在本节结束后进入下一节。独立 Quiz 章节会留给你稍后自行作答。

**适用范围**　v1.7.4 仅匹配 `mooc.mooc.ucas.edu.cn` 上课程编号为 `350140000041158` 的课程。可在学生学习页地址栏核对 `courseId` 的值。其他课程页不会显示学习面板。

**下载**　在本仓库的 **Releases → v1.7.4 → Assets** 中选择 `ucas-mooc-assistant-v1.7.4.zip`。安装只需 Edge 和解压后的文件夹。

## 首次安装

1. 将 ZIP 解压到一个长期保留的文件夹。打开该文件夹，确认里面直接有 `manifest.json`、`assistant.js`、`foreground.js` 和 `pdf-module.js`。
2. 在 Edge 地址栏输入 `edge://extensions` 并按回车，打开「开发人员模式」，点击「加载解压缩的扩展」（界面也可能显示「加载解压缩」）。
3. 选中刚才能看到 `manifest.json` 的那一层文件夹。扩展列表应出现「国科大在线学习助手」，版本号为 **1.7.4**，开关处于开启状态。保留该文件夹，Edge 会从这里加载扩展。
4. 用平时的方式登录国科大在线，进入指定课程，打开具体章节的「学生学习页面」。若安装前章节已经打开，按 `Ctrl+R` 刷新。页面左下角应出现「国科大在线学习助手」。[Microsoft Edge 本地扩展安装说明](https://learn.microsoft.com/zh-cn/microsoft-edge/extensions/getting-started/extension-sideloading)

## 开始、换节与停止

1. 展开左下角面板，点一次 **「开启连续切换」**。课程页保持在前台，同一时间使用一个学习标签页。若课程设置了鼠标移出时暂停，请让鼠标停留在视频画面内。
2. 助手从本节首个可处理的待学任务开始。视频自然播完后再接续下一项。一节里有两段视频和一份 PDF 时，会依次处理这三项。目录右侧黄色数字表示剩余任务点数，其中也可能包含文档或测验。
3. PDF 默认使用 **「直达末页」**。想跟随阅读时，可在「PDF 阅读速度」里选择慢速、标准、快速或手动滚动。文档追加页面时，助手会继续滚动正文，实际完成情况以课程平台的标记为准。
4. 本节结束后，助手点击页底「下一节」，新节从顶部开始。独立 Quiz 或已识别的纯习题章节会跳过。若平台弹出「当前章节还有任务点未完成」并提供「下一节」，助手会选择「下一节」。被课程先修条件锁住的章节需先满足平台要求。
5. 可随时点 **「关闭连续切换」** 停止接续。如需暂停正在播放的视频，请使用原播放器。连续切换开关和阅读速度保存在当前标签页会话中，同一标签页刷新、换节会沿用。新开学习标签页时请检查面板开关。

## 首次为 PDF 阅读器授权

**同一 Edge 配置中，使用同一阅读器域名的 PDF 通常只需授权一次。** 如果正文已经会自动滚动，可以直接继续学习。

1. 遇到未授权的站外阅读器时，把当前 PDF 滚到视野中央。在 **PDF 正文文字或封面图片中间** 右击，选择 **「为此 PDF 站点启用滚动」**。如果点到章节标题、文档外框或页面空白处，请移到封面中央再试。
2. 如果 Edge 显示站点访问提示，核对阅读器域名，点击允许。左下角面板会显示授权结果，插件会在这份已经打开的 PDF 上启用滚动，无需刷新章节。
3. 换 PDF、换章节或刷新课程页时，只要阅读器域名相同，已有授权会沿用。新阅读器域名、另一个 Edge 配置或已撤销的权限，可能需要再授权一次。
4. 若选择手动阅读，可在 **PDF 正文内部** 滚到底。面板出现「我已读完此 PDF，继续」时，读完后点击即可接续。

## 常见问题

| 现象 | 怎么处理 |
| --- | --- |
| 加载时提示找不到清单 | 确认 ZIP 已解压，选择打开后直接能看到 `manifest.json` 的文件夹。 |
| 已安装，左下角没有面板 | 在 `edge://extensions` 确认插件已启用。核对课程编号，打开具体章节，然后刷新该页。 |
| 视频停在中央播放按钮 | 将 Edge 和课程标签页切回前台。助手会等待播放器准备好并重试；面板明确提示需手动播放时，点一次原播放器的 ▶。已经手动暂停的视频可从原播放器恢复。 |
| 课程页面滚动了，PDF 还停在封面 | 把目标 PDF 放在视野中央，点「从当前 PDF 继续」。如提示站点访问受限，按上节在 PDF 正文上右击授权。Edge 内置 PDF 阅读器可能需要手动滚动。 |
| PDF 已到末页，绿勾暂时没出现 | 核对刚看完的那份 PDF 外框上的任务标记。扩展按自身滚动进度接续，学时和任务状态由课程平台记录。 |
| 面板有「导出旧版习题清单」 | 此按钮仅用于取回旧版本在本机保存过的记录。1.7.4 会跳过已识别的独立习题页，不新增习题记录。 |

## 权限与数据

扩展在指定课程页面读取课件位置并操作原播放器。`contextMenus` 提供 PDF 右键菜单，`scripting` 启用阅读器脚本，`storage` 用于读取旧版习题记录。清单中的可选 HTTPS 站点范围用于兼容不同阅读器；实际右键授权时只向 Edge 申请当前阅读器主机的权限。课程登录仍在学校网站进行。

## 更新、卸载与反馈

- **更新已有安装**。关闭连续切换，将新版 ZIP 解压到原安装目录并替换旧文件，在 `edge://extensions` 点击该扩展卡片的「重新加载」，然后刷新课程页核对版本。若已经在用 1.7.4，可以继续使用现有安装。
- **停用或卸载**。在 `edge://extensions` 关闭扩展开关即可停用；选择「删除」可以卸载。重新安装后可能需要重新授予阅读器权限。
- **报告问题**。在本仓库的 Issues 中写明 Edge 版本、扩展版本、任务类型、面板原文和复现步骤。需要配图时，请裁掉地址栏、姓名、学号和课程水印。请勿附上带有登录参数的完整课程链接。

## 验证范围

项目已有的本地 Edge 验证覆盖了同节多个播放器、延迟加载、整页和同址换节、连续 Quiz、存在内外两层滚动条的 PDF、末页延迟追加，以及授权后在已打开的同域阅读器中继续。平台页面更新、课程解锁条件和浏览器原生阅读器可能影响表现。
